## Construire une application de recommandation produit

Ce chapitre couvre les concepts essentiels de construire une application de recommandation produit.

### Introduction

À l’aide de Bubble et d’une API de filtrage collaboratif, vous développerez une marketplace où chaque visiteur reçoit des suggestions personnalisées. Le chapitre détaille la création de la base de données, l’intégration du modèle de recommandation (Google Recommendations AI ou un modèle open‑source hébergé) et le design d’une interface mobile‑first adaptée aux utilisateurs africains.
